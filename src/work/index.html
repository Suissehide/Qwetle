Les questions que l'on nous pose avant de signer.

Cela dépend de ce que le site doit faire, pas du nombre de pages. Un site vitrine sur-mesure et une application métier ne jouent pas dans la même catégorie. Nous donnons un ordre de prix dès notre première réponse, avant tout rendez-vous, pour que personne ne perde son temps : si le budget n'est pas là, nous vous le disons tout de suite.

Comptez quelques semaines pour un site vitrine, plusieurs mois pour une application métier. Le délai dépend surtout d'une chose : la vitesse à laquelle vos contenus et vos validations arrivent. Nous vous annonçons une date au devis, et nous vous prévenons dès que quelque chose menace de la décaler.

Oui, et c'est souvent la bonne décision. Nous commençons par un diagnostic : ce qui fonctionne, ce qui ralentit, ce qui expose vos données. Vous décidez ensuite en connaissance de cause entre la reprise et la refonte — nous n'avons aucun intérêt à vous vendre la plus chère des deux.

Vous connaissez votre métier mieux que nous : les contenus viennent de vous. Nous vous donnons la trame, le nombre de signes par bloc et les formats d'image attendus, puis nous reprenons et resserrons l'ensemble pour le web. Si vous préférez déléguer entièrement la rédaction, nous vous le chiffrons à part.

Le code, le nom de domaine et les accès sont à vous, et le code est écrit pour qu'un autre développeur puisse le reprendre. Aucun abonnement caché, aucune brique maison indispensable pour que le site continue de tourner. Nous préférons que vous restiez parce que le travail vous convient, pas parce que vous êtes coincés.
