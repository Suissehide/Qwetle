Gachapon

Jeu de collection multijoueur dans le navigateur : tirage en 3D, collection de cartes, échanges entre joueurs.

Type
Jeu multijoueur
Rôle
Conception, développement, déploiement
Technologies
React, React Three Fiber, Fastify, PostgreSQL, Redis
En ligne
gachapon.qwetle.fr

Objectif

Porter dans le navigateur une mécanique de gachapon complète : le tirage lui-même en 3D, et autour de lui une application de collection avec comptes, économie de jetons et échanges.

Le produit devait tenir des taux de tirage annoncés et vérifiables, et donner de quoi revenir chaque jour : quêtes, progression, classements, équipes.

Catalogue
329 cartes, 539 variantes
Progression
Niveaux, quêtes, succès, saisons
Multijoueur
Équipes, échanges, trois classements

Architecture

Front React et Vite, scène de tirage en React Three Fiber, routage et cache par TanStack. Back Fastify sur Prisma et PostgreSQL, Redis pour l’état partagé, MinIO pour les fichiers, authentification par mot de passe ou par Google et Discord.

Les taux de tirage, la garantie de légendaire, le recyclage des doublons et les échanges sont arbitrés côté serveur. C’est ce qui rend le taux annoncé opposable plutôt que déclaratif.
